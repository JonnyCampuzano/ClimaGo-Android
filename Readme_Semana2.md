## Avance de la semana 2

Durante la segunda semana se implementó el consumo de la API
Open-Meteo mediante Retrofit.

### Funcionalidades implementadas

- Permiso de acceso a internet.
- Configuración de Retrofit.
- Servicio de geocodificación.
- Búsqueda de ciudades reales.
- Resultados mostrados mediante LazyColumn.
- Consulta del clima por latitud y longitud.
- Visualización de temperatura, humedad y viento.
- Manejo de estados de carga, éxito y error.
- Uso de corrutinas y StateFlow.
- Navegación desde búsqueda hasta detalle.

### API utilizada

Open-Meteo:

- Geocoding API para buscar ciudades.
- Weather Forecast API para consultar el clima.

La API no requiere una clave para el uso académico realizado
en este proyecto.
